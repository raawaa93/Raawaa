## Tag format

`archive/branches/YYYY-MM-DD/<original-branch-name>`

## Restore a branch

```bash
git fetch origin --tags
git switch -c <original-branch-name> <archive-tag>
git push -u origin <original-branch-name>
```

To inspect available archives:

```bash
git tag --list 'archive/branches/*'
```

Do not delete archive tags as part of routine cleanup. They preserve the original commit objects, including work from closed-unmerged PRs. The workflow run summary and this index are the recovery record.

## Safety guarantees

- Only explicitly reviewed branch names and exact 40-character SHAs are eligible.
- Any branch with an open same-repository PR is retained.
- The workflow creates or verifies the annotated tag, checks the tag target SHA, re-reads the live branch head, and only then deletes the branch ref.
- Any changed head, tag mismatch, API failure, or deletion failure is retained/reported rather than silently discarded.
- `main`, backups, recovery, restore, release, production-deploy, deploy, and preview-deploy namespaces are never archived.
